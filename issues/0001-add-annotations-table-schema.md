## What to build

Create an `annotations` table in the database schema to store PNG blobs of hand‑drawn code annotations. The table will have columns for id, session_id (FK), image_blob, and timestamps.

## Acceptance criteria
- [ ] Table has columns: id, session_id, image_blob, created_at.
- [ ] Foreign key constraint on session_id referencing practice_sessions.id.
- [ ] Migration script is generated by Sequelize CLI.
