## What to build

Develop a TypeScript module that manages the HTML5 canvas overlay, implementing brush drawing, color selection, and eraser functionality. The engine should expose an API for recording strokes.

## Acceptance criteria
- [ ] Canvas context is properly initialized with transparent background.
- [ ] Brush tool draws continuous lines at user‑defined width/color.
- [ ] Eraser tool removes pixels within a defined radius.
- [ ] Engine exposes `exportToBase64()` method to capture the current canvas state as PNG.
