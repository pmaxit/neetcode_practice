## What to build

Develop a React component that renders the source code image as background and provides an overlay canvas with drawing tools (brush, color picker, eraser). The component should manage its own state for tool selection.

## Acceptance criteria
- [ ] Component renders correctly on top of the practice panel.
- [ ] Canvas overlay is responsive to touch/mouse events.
- [ ] Tool palette allows switching between brush/eraser and selecting colors.
- [ ] “Save” button triggers export of canvas content via the API endpoint.
