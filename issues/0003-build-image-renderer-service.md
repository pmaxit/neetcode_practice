## What to build

Implement a utility service that converts source code text into a PNG image with syntax highlighting and line numbers, using the same rendering engine as the main practice editor.

## Acceptance criteria
- [ ] Service accepts a file path or content string.
- [ ] Renders code with correct syntax highlighting (based on language detected).
- [ ] Generates a PNG buffer ready for export.
- [ ] Exposes `renderToBase64()` method returning base64 encoded image data.

## Blocked by
None - can start immediately
